# KHEDMA — Morocco Local Services Marketplace

Ready-to-run static website for GitHub Pages.

## Files
- index.html
- style.css
- script.js

## GitHub Pages
1. Create a new GitHub repository.
2. Upload these 3 files to the repository root.
3. Open Settings → Pages.
4. Select Deploy from branch → main → / (root).
5. Save and wait for GitHub Pages to publish.

No build step is required.

## Languages
English, Français, العربية are included in the interface.

## Important
The professional cards are demo data for the UI. Do not present them as real verified professionals until real providers are onboarded.
