# KHEDMA V11 — Morocco Focus + Stable Profile Modal

Static GitHub Pages frontend.

## What changed
- Profile modal now has a high-contrast, always-visible close button.
- Morocco map is tightly focused on Morocco and visually clipped to the Morocco silhouette; no world-map presentation.
- City selection no longer zooms the country map away from Morocco.
- Lightweight animations remain; no heavy 3D dependency.
- English / French / Arabic + RTL remain supported.

## GitHub Pages
Upload `index.html`, `style.css`, `script.js`, and `README.md` directly into the repository root.
