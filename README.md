# KHEDMA V28 — PRO

V28 adds KHEDMA PRO foundations on top of V27:
- PRO professional status managed by admin
- Featured placement for 30 days
- PRO request workflow (no payment connected yet)
- Lead-alert preference
- Real profile view / WhatsApp / call analytics events
- PRO ranking and featured ranking for published professionals
- Arabic / French / English support

## Supabase
Run the complete `supabase.sql` in Supabase SQL Editor. It includes all previous KHEDMA tables plus V28 tables/columns.

## Deploy
Keep these files at the GitHub Pages repository root:
`index.html`, `style.css`, `script.js`, `supabase-config.js`, `supabase.sql`, `README.md`

Do not expose a Supabase service-role/secret key in the browser.

## PRO payments
Payment is intentionally NOT connected in V28. Admin can activate PRO manually for testing/validation. Payment can be connected after the business model is validated.

## V29 — Notifications, Lead Management & Moderation
Run `supabase.sql` in Supabase SQL Editor. V29 adds in-app notifications, professional lead accept/decline actions, profile reporting, customer blocking, admin moderation, and automatic notifications when a request is matched.


V30 — Stability & professional reviews. Fixes the Admin Reviews schema-cache error, adds a professional Reviews dashboard showing customer ratings/comments, makes the overview stats role-aware, and adds review indexes. Run the updated supabase.sql.


V32 — Production matching hardening and review UX. Matching is now generated by a database trigger instead of the browser, blocked professionals are excluded from matching, the request is linked to the professional who actually contacts the customer, and the customer review panel explains eligibility clearly.


## V33 — Search, Service Cards & UX Polish
- Service cards are now clickable and run real Supabase professional filtering.
- Search filters published professionals by service and city.
- City selection now filters the public professional results.
- Empty professional states are localized and include a useful next action.
- The public professionals section is labeled PROFESSIONALS instead of FEATURED unless a professional is actually featured.
- Featured/PRO labels are shown on matching professional cards.
- Fixed the missing `review_eligibility_hint` translation key in EN/FR/AR.
- Added keyboard accessibility for service cards.
- No database migration is required for V33.

### V33 test

3. Click Plumbing, Electricity or Painting.
4. Choose a city and confirm the professional list changes.
