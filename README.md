# KHEDMA V9 — Real Morocco Map + Fully Responsive

This version fixes the blank map and mobile overflow issues found in V8.

- Real interactive OpenStreetMap/Leaflet map when online.
- Real Morocco GeoJSON boundary and local fallback when map CDN/tiles fail.
- Interactive city markers.
- Responsive mobile/tablet/desktop layout.
- Horizontal overflow prevented.
- Animated map markers, service cards and professional profiles.
- Arabic RTL, French and English.
- Demo data remains clearly labeled as demo / not verified.

## GitHub Pages
Upload `index.html`, `style.css`, `script.js` and `README.md` directly into the repository root.

The real map needs an internet connection to load OpenStreetMap tiles. If those tiles fail, the site automatically shows the embedded geographic fallback instead of a blank area.
