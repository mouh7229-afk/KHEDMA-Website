# KHEDMA V6 — 3D Morocco / Motion / Nationwide Cities

V6 was audited and rebuilt from the previous frontend.

## Main improvements
- More realistic 3D-style Morocco map with layered extrusion, terrain lines, depth, region pins and motion.
- Nationwide city coverage: 77 city entries in the frontend selectors and city grid.
- Arabic / French / English translations with proper RTL for Arabic.
- Animated professional profile icons and animated service icons.
- Clickable city pins and city cards feed the search.
- Improved mobile navigation accessibility and reduced-motion support.
- Demo data remains clearly marked as demo / not verified.
