# KHEDMA V2 — GitHub Ready

This version is a redesigned frontend for the KHEDMA local-services marketplace.

## Files
- `index.html`
- `style.css`
- `script.js`

Keep the three files in the same folder.

## What's improved
- New KHEDMA logo mark (inline SVG, no external logo file needed)
- Stronger 3D hero scene with depth layers, map plane, rings and parallax
- More coherent blue / violet / cyan visual system
- Richer homepage structure
- Request modal demo
- Real mobile navigation instead of a fake toast
- EN / FR / AR language switching with Arabic RTL
- More Morocco-wide cities
- Professional-focused section
- Sample profiles are clearly marked as DEMO so no fake verification/reviews are presented as real
- Responsive mobile layout
- Reduced-motion support

## GitHub Pages
1. Create a GitHub repository, for example `khedma`.
2. Upload `index.html`, `style.css` and `script.js` to the repository root.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save and wait for GitHub Pages to publish.

## Important
This is still a frontend prototype. Real professionals, WhatsApp numbers, reviews, authentication, requests and database data should be connected later with Supabase or another backend.
